## 2. 通用数学骨架（10 条，背下来就够用）

**① RTP 的定义**
```
RTP = Σ(每种中奖组合的出现机率 × 该组合赔率)
```
它是长期统计值，不是单局保证；分模块后：
```
总 RTP = 主游戏 RTP + Free Game RTP + Bonus RTP + Jackpot RTP
```
出处：运气工程②、入门 PartI（总期望值 ≈ 80.05%，所有可能数 3,200,000 = 20⁵）

**② 组合计数（全库用得最多的一步）**
```
出现次数 = Π 各转轮该图案的次数          （PRODUCT + VLOOKUP）
出现机率 = 出现次数 ÷ Π 各转轮格数        （PartI：÷ 3,200,000）
期望值   = 机率 × 得分（赔率 × 注额）
```
含 WILD 时常见写法：`出现次数 = Π(图案次数 + W个数) − Π(图案次数)`（扣掉「一个 W 都没用到」的纯符号组合）。

**③ 三指标协同（数值策划第一道守门线）**
```
RTP ≈ Hit Rate × 平均中奖金额 ÷ 单次投注额
```
提高 Hit Rate 就必须压低平均奖额；反之亦然。同 RTP 可做出三种体感：高频低奖 / 中频中奖 / 低频高奖。

**④ 空转与节奏**
```
连续 k 转不中（空转）= (1 − HitRate)^k
每局触发机率 p = 1/N  →  连续 k 局不触发 = (1 − 1/N)^k ≈ e^(−k/N)
N 局内达到 50% 触发所需局数 K = ⌊N × ln2⌋ ≈ 0.693N
```
出处：运气工程①（空转概率、95% 分位最长空转）、专题-免费游戏触发（ln2 的来历）

**⑤ 免费游戏与再触发（几何级数）**
```
再触发平均局数 X = 1 ÷ (1 − Σ Pₖ·Sₖ)      （Pₖ = 一次免费里触发 k 次的机率，Sₖ = 追加次数）
免费游戏 RTP = Σ 触发率 × 单把免费 RTP × (初始次数 × X)
```
示例（PartII）：主游戏 65.00% + 免费 39.76% = 总 RTP 104.76%，X = 1.40018608

**⑥ 二项分配（必背）**
```
P(恰好 k 次) = C(n,k) · pᵏ · (1−p)ⁿ⁻ᵏ
Excel：=BINOMDIST(k, n, p, FALSE)         恰好 k 次
       =1-BINOMDIST(k-1, n, p, TRUE)     至少 k 次（区间）
       =BINOM.DIST.RANGE(n, p, 下限, 上限) 区间机率
```
陷阱：不同图案的个数互相关联，**不能把各自「恰好 3 个」的机率相乘**；同一滚轮的多行也不独立（一条带上符号位置固定）。

**⑦ 马可夫链（状态迭代）**
```
πₙ₊₁ = πₙ · M           （Excel：=MMULT(上一轮分布, 转移矩阵)）
```
转移矩阵的每一行 = 「从此状态出发」的机率分布。再触发、黏性百搭、多轮收集本质都是它。

**⑧ 条件机率与组合数（随机百搭、收集类）**
```
P(状态 | 开了 k 格) = C(k, 需要的格数) ÷ C(总格数, k)
例：C(10,7) ÷ C(15,10)
```

**⑨ 波动率**
```
均值 μ = Σ pᵢxᵢ，方差 σ² = Σ pᵢ(xᵢ − μ)²，波动率 σ = √σ²
```
高波动＝大奖稀但爽感强；低波动＝奖励均匀。调参时波动率与 Hit Rate、RTP 必须一起动。

**⑩ 其它博弈的收益式**
```
捕鱼：击杀率 P = R ÷ N          ｜ 一发打中 K 只鱼 → 修正 P/K
      雷射炮 Pᵢ = W ÷ (Nᵢ × K)   ｜ 平均赔率 = (上限 + 下限) ÷ 2
骰宝：RTP = Chance × (Odds + 1)（+1 是把本金赔回来），总组合 6³ = 216
宾果：单格机率 → 具名图案 → 线条容斥（同家族单组交集 = 7 格）
```

## 10. 附录 A：常见错误与除错清单（摘自《机率新手除错指南》）

### A1. 程序侧（模拟与 Excel 对不上时先查这些）
1. **Feature 类**（Locked Wild 盘面变形）要非常清楚「先算分还是先变化」——顺序搞错结果差很多。
2. **Pay Table 数值**必须核对（作者曾把 200 写成 20，结果整包炸掉）。
3. **自然机率抽取后写入盘面的位置**要对（曾发生 Reel 2 抽完写到 Reel 3）。
4. **Locked Wild 与 Scatter 同时出现**的编码：Locked Wild = 15、Scatter = 16、同时出现 = 17。
5. **Line / Way Game 算分逻辑**写对一次通常会一直沿用，出错概率低，但仍要验证。

### A2. Excel 侧
1. **尽量不要复制粘贴**：把 A3 复制到 B3 后再改 A3，B3 不会跟着变 → 用 `=A5` 引用。
2. **Way Game 滚轮表末尾要补对应图示**，并确认数量正确（PartIV）。
3. **滚轮表长度 = 计算长度**（假设盘面 2×3 时尤其容易错）。
4. **马可夫链是否拉错**（数字差距大时先查这里）。

### A3. 程序与 Excel 对不起来时的排查顺序
1. 先查 Excel：`MID` 找出的值对不对、范围抓得对不对。
2. 再查程序：① 宣告类（Pay Table）→ ② 逻辑 → ③ 加 `printf` / `Console.WriteLine` 看先后顺序 → ④ C# 单步执行 + 断点看 dictionary / 值。
